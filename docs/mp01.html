Mini-Project 1: Exploring Netflix Viewing Data


Using data from Netflix on their catalog and audience viewership, we can run analysis on their performance over the last 3 years, and create a strategy for their business moving forward into 2027.

In order to analyze this data, we will need to load it from Netflix’s website.

Step 1: Loading the data

Show Code 
load_netflix_data <- function(){
  # Note to students: Make sure you have installed the tidyverse and fs packages
  #                   before beginning this assignment. If you aren't sure,
  #                   simply run `library(tidyverse)` at your R Console and, if
  #                   you don't see an error message, `tidyverse` has been 
  #                   installed. (Same for `fs`) If you still need to install
  #                   either package, use the `install.packages` function as 
  #                   demonstrated in class.
  library(tidyverse)
  library(rvest)
  library(readxl)
  library(fs)
  
  data_dir <- path("data", "mp01")
  
  if(!dir_exists(data_dir)){
    dir_create(data_dir, showWarnings=FALSE, recurse=TRUE)
  }
  
  NETFLIX_URLS <- list(
    `2023H1` = "https://about.netflix.com/news/what-we-watched-a-netflix-engagement-report",
    `2023H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2023",
    `2024H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2024",
    `2024H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2024",
    `2025H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2025",
    `2025H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2025",
    `2026H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2026"
  )
  
  download_if_needed <- function(url, local){
    if(!file_exists(local)){
      download.file(url, local, quiet = TRUE, mode = "wb")
    }
    
    return(local)
  }
  
  NETFLIX_URLS |> 
    map(read_html) |> 
    map(html_element, xpath = "//a[contains(@href, '.xlsx')]") |> 
    map_chr(html_attr, "href") |> 
    enframe("period", "url") |> 
    mutate(path = path(data_dir, paste0(period, ".xlsx")), 
           path = map2(url, path, download_if_needed), 
           sheets = map(path, excel_sheets)) |>
    unnest(sheets) |> 
    mutate(data = map2(path, sheets, \(x, y) read_excel(x, sheet=y, skip=3, na="*")), 
           data = map(data, \(x) x |> mutate(`Release Date` = as.Date(`Release Date`))), 
           data = map2(data, sheets, \(x, y) x |> mutate(sheet=y))) |> 
    unnest(data) |> 
    select(-url, -path, -sheets) |> 
    mutate(year=str_sub(period, 1, 4), 
           half=str_sub(period, start=6), 
           period_start = make_date(year, if_else(half==1, 1, 7), 1), 
           period_end = make_date(year, if_else(half==1, 6, 12), if_else(half==1, 30, 31))) |> 
    filter(!is.na(`Hours Viewed`)) |>
    mutate(live_event = !is.na(Runtime) & str_detect(Runtime, "\\d+:\\d+\\*"), 
           clean_time = str_remove(Runtime, fixed("*")),
           Runtime = 60 * hour(hm(clean_time)) + minute(hm(clean_time)),
           title_type = replace_values(sheet, 
                                       "Shows" ~ "TV",
                                       "Film" ~ "Movies",
                                       "Engagement" ~ NA)) |>
    select(-clean_time, -sheet) |>
    mutate(Runtime = coalesce(Runtime, mean(Runtime, na.rm=TRUE)), 
           .by=Title, 
           Title = stringi::stri_trans_general(Title, "Latin-ASCII"),
           Title = str_remove(Title, " // .*"), 
           Title = str_remove(Title, "[^[:ascii:]].*"), 
           Title = str_trim(Title)) |>
    filter_out(Title == "") |>
    select(year, 
           period, 
           period_start, 
           period_end, 
           Title, 
           -half, 
           Runtime, 
           Views, 
           `Hours Viewed`, 
           `Release Date`,
           `Available Globally?`, 
           live_event, 
           title_type) |> 
    group_by(Title) |> 
    fill(title_type,
         .direction="updown") |>
    ungroup()
  
}

table_3 <- NETFLIX_DATA |>
  group_by(title) |>
  summarize(
    avg_views = mean(views, na.rm=TRUE),

The shows with consistently high viewership across all 7 periods recorded were Better Call Saul, Superstore, and Breaking Bad. Multiple seasons of Better Call Saul and Breaking Bad appeared in the list, so people are re-watching these shows often. In order to calculate the consistency score, I counted how many times each show appeared in the database, and limited the search to only shows that appeared in all 7 periods. Then I ranked those shows based on average viewership, the minimum amount of views they recieved, and the standard deviation of their views. I added those metrics together in a weighted formula, with average views accounting for 50% of the score, and minimum/std. dev. views each accounting for 25% of the score.

Step 7: Corporate Strategy Memo


Invest in Bite-Sized Content to Promote Larger Titles
When it comes to “bite-sized” content, people typically look to social media platforms such as Tik-Tok, Instagram, and Youtube. Most of the content on these platforms are user generated, and the quality can vary depending on who posted.

Bite-sized content makes up a very small portion of Netflix’s catalog, about 0.66%. However, the average bite gets a total of 2,355,616 views, and the top bites rack in tens of millions of views.

Allow More Titles to be Globally Available
As shown in Step 5, only 21.7% of titles on Netflix are available globally. However, globally available titles drive almost half of the audience engagement, accounting for 48.0% of total views, and 49.0% of hours viewed.

Allowing content to be available globally introduces new audiences to titles they might not have seen otherwise. Expanding global distribution rights for existing popular region-locked titles, and ensuring global releases for new titles can increase viewership and platform engagement.
